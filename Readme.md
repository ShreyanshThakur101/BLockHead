# Simulating BLock-Chain for ML based consensus voting
##### visit at "https://b-lock-head.vercel.app/"
### Why 
In POS systems there is a problem of invalid validators having the grater stake. So to combact that we are trying to implement ml based validating of validator and comparing the percaent of compromised voting session with triditional consesus voting.

### Methord
Will be simulating an small scale pos block-chain

And creating around 100 users and 10000 blocks of past transactions.

This will ensure sufficiat data for ml training

The following structure will be followed :-
    compare the results of:

    Traditional PoS
        ↓
    Validator selected primarily using stake
        ↓
    Vote
        ↓
    Consensus

    against:

    ML-Assisted PoS
        ↓
    Analyse validator behaviour
        ↓
    Calculate validator reliability
        ↓
    Combine reliability + stake
        ↓
    Vote
        ↓
    Consensus

### Parameters
1. Number of Validators
2. Percentage of Compromised Validators
